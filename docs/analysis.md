# 一般会計税収/名目GNI比の推移（1994年度〜2023年度）

## データ概要
- 財務省が公表する一般会計決算税収と、内閣府「国民経済計算 年次推計」における名目GNI（年度値）を突き合わせて比率を算出した。【F:data/general_account_tax_revenue_vs_gni.csv†L1-L31】
- グラフは`scripts/plot_tax_gni_ratio.py`でSVGとして生成できる。出力先は`output/general_account_tax_gni_ratio.svg`。【F:scripts/plot_tax_gni_ratio.py†L1-L131】
- 比率は「税収 ÷ 名目GNI × 100」で算出しており、四捨五入して小数第2位まで表示している。【F:data/general_account_tax_revenue_vs_gni.csv†L4-L31】

## 主な傾向
1. **1990年代後半〜2000年代前半の低下局面**：名目GNIが停滞する中、税収/GNI比は8〜9%台まで低下し、リーマンショック直後の2009年度には7.72%まで落ち込んだ。【F:data/general_account_tax_revenue_vs_gni.csv†L4-L21】
2. **消費税増税と景気回復による押し上げ**：2014年度の消費税8%化を境に比率は9%台後半へ上昇し、2017〜2018年度はほぼ横ばいで推移した。【F:data/general_account_tax_revenue_vs_gni.csv†L22-L28】
3. **2021〜2022年度の一時的な上振れ**：コロナ禍後の企業業績回復と資産価格上昇で税収が大きく伸び、比率は11%台まで上昇したが、2023年度は10.59%とやや反落している。【F:data/general_account_tax_revenue_vs_gni.csv†L27-L31】

## 取得・加工手順
1. 財務省サイトに掲載された決算ベースの「一般会計税収の推移」から1994年度以降の税収（兆円）を転記。
2. 内閣府SNAの年度別名目GNI系列（付表1-1）を抽出し、兆円換算で整形。
3. 上記2系列を`data/general_account_tax_revenue_vs_gni.csv`にまとめ、Pythonスクリプトで比率と可視化用SVGを生成。【F:data/general_account_tax_revenue_vs_gni.csv†L1-L31】【F:scripts/plot_tax_gni_ratio.py†L1-L131】
